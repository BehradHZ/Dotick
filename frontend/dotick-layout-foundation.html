English UI typeface

Inter — what this prototype actually uses
Postpone all overdue tasks
Inter is the standard free/open stand-in for SF Pro: built for screens, tabular figures, optical sizing, and — critically — actually licensed for shipping in a product. Apple's real SF Pro EULA restricts it to Apple-platform software/mockups, so it can't legally ship in Dotick's web app.
System font stack (-apple-system) — for comparison only
Postpone all overdue tasks
This renders as actual San Francisco on a Mac/iPhone (since it reads the OS's own font), and as Segoe UI / Roboto on Windows/Android. Useful as a reference for "what SF Pro looks like" here, but it's not a consistent, embeddable choice across platforms — Inter is.

Monospace (for numerals, dates, code-like UI)

SF Mono — via system stack, not embedded
Postponed to 14:32 — grace 7d 03h
I couldn't download an SF Mono font file to embed here: developer.apple.com isn't reachable from this environment's network, and separately, SF Mono only ships inside Apple's macOS/Xcode font installer — its license restricts it to Apple-platform software and marketing use, not embedding in a web app like Dotick. This line uses ui-monospace in the font stack instead, so on a Mac or iPhone it renders as real SF Mono automatically (no download needed); on Windows/Linux it falls back to Menlo/Consolas.
JetBrains Mono — what this prototype actually uses (--font-mono)

Same reasoning as Inter vs. SF Pro: this is the licensed, embeddable, cross-platform stand-in — already loaded via Google Fonts and already wired up as --font-mono (used for the list counts and tab counters throughout the shell). Compare its numerals against the SF Mono line above.
