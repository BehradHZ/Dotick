# عملیات امنیت

> وضعیت: نیازمند تدوین

این سند باید رویه‌های مدیریت آسیب‌پذیری و patch، چرخش secretها، پایش رخدادهای امنیتی، پاسخ به incident، گزارش‌دهی، نگهداری شواهد و بازبینی دسترسی‌ها را تعریف کند.

مرز این سند با طراحی امنیت باید روشن باشد: سیاست و کنترل طراحی در `03-design/security-design.md` و اجرای روزمرهٔ آن‌ها در این سند ثبت می‌شود.
