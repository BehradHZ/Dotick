## Start and recover

Follow [environment setup](../docs/development/environment-setup.md). Secrets are generated in the ignored `.env`; no production credentials ship. Compose binds developer ports to loopback and retains PostgreSQL in a named volume. Apply migrations explicitly before starting the API. Stop with `docker compose down` to retain data; volume removal is not a rollback procedure.

This is the initial engineering schema. Subsequent migrations must preserve published migration history. There is no verified production data migration/rollback or production backup-restore claim in this release candidate.
