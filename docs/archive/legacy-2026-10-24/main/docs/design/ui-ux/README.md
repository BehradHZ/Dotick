# طراحی UI/UX

> وضعیت: نیازمند تدوین

این پوشه باید جریان‌های کاربر، معماری اطلاعات، الگوهای تعامل، wireframeها، قواعد responsive، accessibility، design tokenها و تصمیم‌های تجربهٔ کاربری Dotick را نگهداری کند.

هر خروجی طراحی باید دامنه، وضعیت، تاریخ بازنگری و پیوند آن به requirement یا تصمیم مرتبط را مشخص کند.
