# بیانیهٔ محدوده

> وضعیت: نیازمند تدوین

این سند باید محدودهٔ محصول و پروژه را مشخص کند: قابلیت‌های داخل محدوده، موارد خارج از محدوده، تحویل‌دادنی‌ها، قیود، وابستگی‌ها، فرضیات و معیارهای پذیرش سطح‌بالا.

مرز Personal V1 و قابلیت‌های آینده باید به‌صورت صریح و قابل ردیابی به نقشهٔ راه و SRS بیان شود.
