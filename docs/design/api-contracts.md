# قراردادهای API

> وضعیت: نیازمند تدوین

این سند باید مرزهای API، قرارداد endpointها، مدل request و response، قواعد اعتبارسنجی، احراز هویت و مجوز، خطاها، pagination، idempotency، versioning و سازگاری عقب‌رو را تعریف کند.

پس از ایجاد OpenAPI، این فایل باید محل نسخهٔ مرجع قرارداد و روش تولید، اعتبارسنجی و انتشار آن را نیز مشخص کند.
